# PO OCR

เครื่องมืออ่านใบสั่งซื้อ (Purchase Order) ด้วย AI ในเครื่อง (Ollama) แล้วเขียนข้อมูลลงชีต `PO` ของไฟล์ Excel (macro SAP สำหรับสร้าง Sales Order อัตโนมัติ)

**ขั้นตอนการทำงาน**

1. อัปโหลดใบ PO (PDF หรือภาพ `png` / `jpg` / `jpeg` เลือกได้หลายไฟล์)
2. ระบบเลือกวิธีอ่านให้เอง
   - PDF ที่มีตัวหนังสือ → อ่านด้วยโมเดลข้อความ
   - ไฟล์สแกน/ภาพถ่าย → อ่านด้วยโมเดลอ่านภาพ (OCR)
3. ตรวจและแก้ข้อมูลในตาราง (ระบบเตือนข้อที่ควรตรวจ และเตือน PO No. ซ้ำ)
4. เขียนต่อท้ายลงชีต `PO` แล้วดาวน์โหลดไฟล์ Excel ใหม่ (ไม่แก้ไฟล์ต้นฉบับ)

**ไฟล์ในโปรเจกต์**

```
po_app.py              หน้าเว็บ (Streamlit)
po_extract.py          อ่าน PO ด้วย Ollama, ตรวจข้อมูล, เขียน Excel
psd2Excel_ollama.py    เวอร์ชันบรรทัดคำสั่ง
requirements.txt       แพ็กเกจ Python
run_po.bat             ตัวติดตั้งและเปิดแอปบน Windows
```

## Installation

### สิ่งที่ต้องมี

- Python 3.10 ขึ้นไป
- [Ollama](https://ollama.com/download) ติดตั้งและเปิดทำงานอยู่
- ไฟล์ Excel ปลายทางที่มีชีตชื่อ `PO` เช่น `PO_Template.xlsm`

### ดาวน์โหลดโมเดล

```bash
ollama pull qwen3.5:4b       # โมเดลข้อความ (ค่าตั้งต้น)
ollama pull qwen2.5vl:7b     # โมเดลอ่านภาพ ต้องใช้เฉพาะ PO สแกน/ภาพถ่าย
```

> โมเดลใหญ่ขึ้นมักอ่านได้แม่นกว่า สามารถเลือกโมเดลอื่นได้ในแถบตั้งค่า (sidebar) ของแอป

### ติดตั้งแพ็กเกจ

**Windows (ง่ายที่สุด):** ดับเบิลคลิก `run_po.bat` — จะสร้าง `.venv` ติดตั้งแพ็กเกจ แล้วเปิดแอปให้เลย

**ติดตั้งเอง:**

```bash
python -m venv .venv
.venv\Scripts\activate           # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```

แพ็กเกจที่ใช้: `streamlit`, `requests`, `pandas`, `openpyxl`, `pdfplumber`

## Run

### แบบหน้าเว็บ

```bash
streamlit run po_app.py
```

หรือดับเบิลคลิก `run_po.bat` (เปิดหน้าต่างค้างไว้ตลอดการใช้งาน)

จากนั้นในแอป:

1. ตั้งค่า Ollama URL และเลือกโมเดลที่แถบด้านซ้าย (ถ้าเชื่อมต่อได้จะขึ้น 🟢)
2. อัปโหลดใบ PO แล้วกด **อ่านข้อมูลด้วย AI**
3. ตรวจ/แก้ข้อมูลในตารางของแต่ละใบ PO
4. เลือกไฟล์ Excel ปลายทาง แล้วกด **สร้างไฟล์ Excel** และดาวน์โหลดไฟล์ผลลัพธ์ (`ชื่อเดิม_updated.xlsm`)

### แบบบรรทัดคำสั่ง

```bash
# อ่านและตรวจอย่างเดียว (ไม่แตะ Excel)
python psd2Excel_ollama.py "PO.pdf" --dry-run

# อ่านแล้วถามยืนยันก่อนเขียนต่อท้ายไฟล์ Excel
python psd2Excel_ollama.py "PO.pdf" "PO_Template.xlsm"

# เขียนเป็นไฟล์ใหม่ โดยไม่ถามยืนยัน
python psd2Excel_ollama.py "PO.pdf" "PO_Template.xlsm" "Output.xlsm" --yes

# PO สแกน / บังคับอ่านจากภาพ
python psd2Excel_ollama.py "scan.pdf" "PO_Template.xlsm" --vision
```

ตัวเลือกอื่น: `--url`, `--model`, `--vision-model`, `--ctx` (ค่าตั้งต้น 12288), `--json ไฟล์.json` (บันทึกข้อมูลที่อ่านได้เป็นหลักฐาน)

## การปรับให้เข้ากับเอกสารของคุณ

แก้ใน `po_extract.py`:

- `COLUMN_HINT` — อธิบายคอลัมน์ในตารางรายการสินค้าให้โมเดลรู้ ให้ตรงกับหัวตารางใน PO ของคุณ
- `write_po_to_sheet()` — ตำแหน่งเซลล์ปลายทาง (ชีต `PO` คอลัมน์ A, B, E, F, J–M, ตัวนับแถวที่แถว 3 คอลัมน์ 36, ข้อมูลเริ่มแถว 6)
- `MATERIAL_CODE_LEN`, `ALLOWED_UNITS` — กฎตรวจข้อมูล

## ข้อควรระวัง

- โมเดลอาจอ่านผิดหรือตกหล่น โดยเฉพาะโมเดลเล็กและเอกสารสแกน **ต้องตรวจข้อมูลก่อนเขียนลง Excel ทุกครั้ง** เพราะข้อมูลนี้จะถูกใช้สร้าง SO ใน SAP
- ข้อมูลถูกส่งไปยัง Ollama URL ที่ตั้งไว้เท่านั้น ควรใช้ Ollama ในเครื่องที่เชื่อถือได้กับเอกสารบริษัท
- ไฟล์ถูกบันทึกผ่าน `openpyxl`: macro ใน `.xlsm` ยังอยู่ แต่ปุ่มฟอร์ม/ActiveX, slicer, Power Query และรูปบางอย่างอาจหาย ควรเก็บไฟล์ต้นฉบับไว้เสมอ
- ก่อนรัน macro ให้เปิดไฟล์ใหม่ตรวจชีต `PO` ก่อน
- ไม่ควร commit ไฟล์ธุรกิจจริง (`*.xlsx`, `*.xlsm`, PDF) ขึ้น git
